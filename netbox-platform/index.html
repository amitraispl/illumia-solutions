The Documentation Problem

Spreadsheets are not infrastructure documentation.

IP address sheets drift from reality the moment they are created. Rack diagrams in Visio are one migration behind. Network topology in a shared wiki is nobody's responsibility.

NetBox makes infrastructure documentation a first-class engineering discipline — API-driven, version-controlled, and integrated directly into your provisioning pipeline.

02Visio or draw.io for rack diagrams

Core Modules

Every layer of network infrastructure, documented.

IPAM

IP Address Management

Hierarchical prefix and IP management across IPv4 and IPv6. Track aggregates, prefixes, IP ranges, and individual addresses with VRF and tenant awareness for overlapping address spaces across multi-tenant environments.

  • Prefix allocation and utilisation tracking
  • VRF and tenant isolation
  • IPv4 and IPv6 dual-stack
  • Import from Infoblox and SolarWinds

Source: netboxlabs.com

DCIM

Data Centre Infrastructure

Rack elevation visualisation, device inventory, power and cooling tracking. Document every device from core router to cable management arm — make, model, serial, asset tag, location, and lifecycle status in one place.

  • Rack front and rear elevation diagrams
  • Device and component inventory
  • Power draw and cooling tracking
  • Site and location hierarchy

Source: netboxlabs.com

Automation

Ansible, Terraform, and CI/CD

NetBox is not a passive documentation tool — it is the authoritative data source for your automation pipeline. Ansible reads dynamic inventory directly. Terraform manages NetBox state as infrastructure code. Webhooks fire on every change.

  • Native Ansible dynamic inventory plugin
  • Official Terraform provider
  • REST API and GraphQL endpoint
  • Webhook triggers for CI/CD

Source: netboxlabs.com

Visualization

See your infrastructure, not just query it.

Rack elevations render every device, patch panel, and PDU as a to-scale diagram — front and rear — generated live from inventory data. No Visio file to keep in sync; the picture is the database, so it's never out of date.

  • Front and rear rack elevation diagrams
  • Auto-generated from live device data
  • SVG export for change requests and audits
  • Device utilisation and space at a glance

Source: netboxlabs.com

Virtualization

Virtual Machines & Clusters

Manage VMs, clusters, and hypervisors alongside physical infrastructure. Track vCPU, memory, and storage allocation with full VM-to-host mapping and cluster utilisation metrics.

  • VM cluster management and host assignment
  • VM-to-host mapping with resource utilisation
  • Seamless physical and virtual inventory in one view

Source: GitHub — netbox-community/netbox

Multi-Tenancy

Tenant Isolation Across All Objects

Enforce tenant awareness across every infrastructure object. Separate IP spaces, VLANs, and device groups per tenant — built for managed service providers and multi-department enterprises.

  • Tenant-scoped views and filtering
  • Cross-tenant security boundaries
  • Overlapping address spaces per tenant via VRF

Source: GitHub — netbox-community/netbox

Extensibility

Extend NetBox Without Code

Add organisation-specific attributes via custom fields and model entirely new infrastructure types with Custom Objects — no code required. Plugin architecture handles anything beyond that.

  • Custom fields on any object type
  • No-code Custom Objects for new data models
  • Plugin architecture for advanced extensions

Source: GitHub — netbox-community/netbox

RBAC

Role-Based Access Control

Fine-grained permissions down to individual objects. Restrict users and groups to specific sites, tenants, or object types with full JSON constraint-based access rules.

  • Object-level permissions with JSON constraints
  • User and group role management
  • SOC 2 and ISO 27001 compliant audit trail

Source: NetBox Labs blog

Topology

Advanced Network Topology

Model BGP sessions, peering relationships, and full device role hierarchies. Visual Explorer renders interactive cable topology, floorplans, and WAN connectivity from your existing NetBox data.

  • BGP communities, route targets, and AS routes
  • Device type templates and role hierarchies
  • Interactive Visual Explorer for topology and racks

Source: netboxlabs.com

Config Templates

Configuration Management & Templates

Render device configurations from Jinja2 templates using NetBox as the authoritative data source. Config contexts deliver device-specific variables to Ansible, Terraform, and custom pipelines.

  • Dynamic Jinja2 config generation per device
  • Config contexts for site and role variants
  • Direct export to Ansible inventory and Terraform

Source: netboxlabs.com

VLAN & VRF

Every VLAN and VRF, queryable as data.

Catalogue every VLAN by site, group, and functional role, with ID-collision prevention built into the model. VRFs, route targets, and BGP communities exist as first-class objects your automation can query instead of reverse-engineering from device configs.

  • VLANs scoped by site, group, and role
  • Collision prevention across the numbering plan
  • VRFs, route targets, and BGP communities as data
  • Direct read access for Ansible and Terraform

Source: GitHub — netbox-community/netbox
